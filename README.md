# 🎮 ES-DE ROMs Folders

A ready-to-use **empty ROM folder structure for ES-DE (EmulationStation Desktop Edition)**.

This pack is for users who want the expected system folders already created so they can simply add their own ROM files.

> **No ROMs, games, BIOS files, ISOs, or copyrighted game content are included.**

---

## 📦 What's Included

This download contains **empty ES-DE system folders only**.

Example:

```text
ROMs/
├── 3ds/
├── gba/
├── gbc/
├── gc/
├── n64/
├── nds/
├── nes/
├── ps2/
├── psx/
├── snes/
├── switch/
└── ...
```

The folders are already organized for use with **ES-DE**.

---

## 📥 Installation

1. Download the ES-DE folders archive.
2. Extract the ZIP file.
3. Open the ROM directory used by **ES-DE**.
4. Copy or move the included folders into your ROM directory.
5. Choose **Merge** if prompted.
6. Add your own ROM files to the appropriate system folders.
7. Open or restart **ES-DE** and rescan your game library if needed.

---

## 🎮 Adding Your Games

Place each ROM in the folder for its corresponding system.

For example:

```text
ROMs/gba/   → Game Boy Advance
ROMs/n64/   → Nintendo 64
ROMs/nds/   → Nintendo DS
ROMs/ps2/   → PlayStation 2
ROMs/psx/   → PlayStation
ROMs/snes/  → Super Nintendo
```

> **Do not rename the folders** unless you know ES-DE expects a different folder name for your setup.
